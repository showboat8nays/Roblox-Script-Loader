## FAQ

### Is XCutors safe to use?

XCutors itself is a clean, open-source launcher. The safety of the individual executors and scripts you run is the responsibility of their respective developers and your own judgment.

### Does it work on all versions of Windows?

XCutors is designed for Windows 10 and Windows 11. Support for older versions like Windows 7 is not guaranteed.

### Do I need to disable my anticomponent?

Some anticomponent software may flag executor files due to their nature. You may need to add exceptions for the XCutors folder and specific executors.

### How do I update to a new version?

Check the Releases page of this repository for the newest installer. Running the new installer over the old version will update it.

### Can I add my own executors to the pack?

The current version of XCutors does not support adding third-party executors to the menu. It is a curated collection of the five included tools.

### Where do I get Lua scripts to run?

You can find scripts from various online script hubs, forums, and communities. Be cautious and scan scripts before use.

### Does this guarantee I won't get banned in Roblox?

No. Using any third-party software to modify or run scripts in Roblox carries a risk of account action, including temporary or permanent bans.
